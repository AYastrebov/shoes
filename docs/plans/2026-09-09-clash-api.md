# Clash API, slice 1 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A mihomo-compatible Clash API plus a Prometheus `/metrics` on the shoes CLI, fed by a per-connection registry counted at the accept edge, with the mobile artifacts unchanged by construction.

**Architecture:** An always-compiled `src/connection_registry.rs` (real behind `control-connections`, a zero-sized shim without it) is registered at every accept edge and filled in as the forward path learns destination, exit outbound and rule. A `src/clash_api/` module behind `clash-api` renders the registry, the outbound registry and the log ring over hyper 1.x with a hand-rolled WebSocket upgrade. `main.rs` starts the listener once, outside the reload loop.

**Tech Stack:** Rust 2024, tokio, hyper 1.x + http-body-util (already deps), serde_json (optional dep, moved to the portable section), `subtle` for the bearer compare, `dashmap` for the registry, the existing `websocket` module's accept-key and frame packer.

**Spec:** `docs/specs/2026-09-09-clash-api.md`. Read it first; every task below cites the section it implements. Prior art is on `feature/control-api`, tip `8e9f8de` — read files with `git show 'feature/control-api:<path>'`, never cherry-pick.

## Global Constraints

- **Mobile untouched by construction.** `clash-api` and `control-connections` are non-default and never appear in `scripts/build-android.sh` or `scripts/build-apple.sh`. No `#[cfg(feature = "control-connections")]` in `src/tcp/tcp_server.rs`, `src/quic_server.rs`, `src/hysteria2/server.rs`, `src/tuic/server.rs`: they call the registry through the shim only.
- **Two module trees.** `src/main.rs` declares the crate's modules itself (it does not `use shoes::`), so every new module is declared in both `src/lib.rs` and `src/main.rs`, with the same `#[cfg]`.
- **Feature graph** (spec, "Where it runs"): `control-connections = ["control-stats"]`, `clash-api = ["control-logs", "control-connections", "dep:serde_json"]`, `desktop` unchanged.
- **Bind rule** (spec, "Authentication, binding and CORS"): a non-loopback `listen` with no `secret` is a validation error. Secret compare is `subtle::ConstantTimeEq`.
- **Counting** at the client edge: `up` = bytes read from the client, `down` = bytes written to it. Per-poll path touches only the connection's own atomics; process-wide and per-inbound counters are folded once, in `Drop`.
- **Cap** (spec, "The cap"): beyond `max_tracked_connections` live entries the connection is served, not tracked, and `untracked` increments.
- **Every claim gets a test at the level where a missing call is visible.** Wire-level tests go through a real listener on `127.0.0.1:0`.
- **Gates for every task:** `cargo fmt --all -- --check`, `cargo clippy --locked --features clash-api --bins --tests -- -D warnings`, `cargo test --locked --features clash-api`, and `cargo build --locked --features control-stats` (the mobile set still compiles).
- **Environment:** `export PATH=$HOME/.rustup/toolchains/stable-aarch64-apple-darwin/bin:$HOME/.cargo/bin:$PATH` before any cargo command. Commits use `git -c user.email=ayastrebov@gmail.com commit`. There is no `timeout` on macOS; use `perl -e 'alarm 300; exec @ARGV' -- cargo test ...` if a test can hang.

pub struct ClashApiConfig {
    pub listen: SocketAddr,
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub secret: Option<String>,
    #[serde(default, skip_serializing_if = "Vec::is_empty")]
    pub allow_origins: Vec<String>,
    #[serde(default = "default_cap")]
    pub max_tracked_connections: usize,
    #[serde(default, skip_serializing_if = "Option::is_none")]

impl ClashApiConfig {
    /// The bind rule: loopback may go without a secret, nothing else may.
    pub fn validate(&self) -> std::io::Result<()> {
        if let Some(secret) = &self.secret
            && secret.is_empty()
        {
            return Err(std::io::Error::new(
                std::io::ErrorKind::InvalidInput,
                "clash_api.secret is empty; remove the field or give it a value",
            ));
        }
        if !self.listen.ip().is_loopback() && self.secret.is_none() {
            return Err(std::io::Error::new(
                std::io::ErrorKind::InvalidInput,
                format!(
                    "clash_api.listen is {} which is reachable from other hosts, so \
                     clash_api.secret is required",
                    self.listen
                ),
            ));
        }
        if self.max_tracked_connections == 0 {
            return Err(std::io::Error::new(
                std::io::ErrorKind::InvalidInput,
                "clash_api.max_tracked_connections must be at least 1",
            ));
        }
        Ok(())
    }
}

```rust
//! One entry per live connection, counted at the accept edge.
//!
//! Lifted from `feature/control-api` (see the spec's "Prior art") and
//! extended with what a Clash connection object needs: destination, exit
//! outbound, rule, and a way to close. Always compiled: without
//! `control-connections` every call here is an inlined no-op and the accept
//! loops carry no `#[cfg]`.

use std::net::SocketAddr;
use std::pin::Pin;
use std::sync::Arc;
use std::sync::atomic::{AtomicU64, Ordering};
use std::task::{Context, Poll};

use tokio::io::{AsyncRead, AsyncWrite, ReadBuf};

use crate::address::NetLocation;
use crate::async_stream::{AsyncPing, AsyncStream};

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Network {
    Tcp,
    Udp,
}

impl Network {
    pub fn as_str(self) -> &'static str {
        match self {
            Network::Tcp => "tcp",
            Network::Udp => "udp",
        }
    }
}

/// The per-connection atomics. `up` is bytes read from the client, `down`
/// bytes written to it.
#[derive(Debug, Default)]
pub struct ConnectionCounters {
    pub up: AtomicU64,
    pub down: AtomicU64,
}

/// Wraps a client stream and counts into `counters`. Forwards vectored
/// writes and pings so it never disables a fast path.
pub struct CountingStream<S> {
    inner: S,
    counters: Arc<ConnectionCounters>,
}

impl<S> CountingStream<S> {
    pub fn new(inner: S, counters: Arc<ConnectionCounters>) -> Self {
        Self { inner, counters }
    }
}

impl<S: AsyncRead + Unpin> AsyncRead for CountingStream<S> {
    fn poll_read(
        mut self: Pin<&mut Self>,
        cx: &mut Context<'_>,
        buf: &mut ReadBuf<'_>,
    ) -> Poll<std::io::Result<()>> {
        let before = buf.filled().len();
        let r = Pin::new(&mut self.inner).poll_read(cx, buf);
        if let Poll::Ready(Ok(())) = &r {
            let read = buf.filled().len() - before;
            if read > 0 {
                self.counters.up.fetch_add(read as u64, Ordering::Relaxed);
            }
        }
        r
    }
}

impl<S: AsyncWrite + Unpin> AsyncWrite for CountingStream<S> {
    fn poll_write(
        mut self: Pin<&mut Self>,
        cx: &mut Context<'_>,
        buf: &[u8],
    ) -> Poll<std::io::Result<usize>> {
        let r = Pin::new(&mut self.inner).poll_write(cx, buf);
        if let Poll::Ready(Ok(n)) = &r {
            self.counters.down.fetch_add(*n as u64, Ordering::Relaxed);
        }
        r
    }
    fn poll_flush(mut self: Pin<&mut Self>, cx: &mut Context<'_>) -> Poll<std::io::Result<()>> {
        Pin::new(&mut self.inner).poll_flush(cx)
    }
    fn poll_shutdown(mut self: Pin<&mut Self>, cx: &mut Context<'_>) -> Poll<std::io::Result<()>> {
        Pin::new(&mut self.inner).poll_shutdown(cx)
    }
    fn poll_write_vectored(
        mut self: Pin<&mut Self>,
        cx: &mut Context<'_>,
        bufs: &[std::io::IoSlice<'_>],
    ) -> Poll<std::io::Result<usize>> {
        let r = Pin::new(&mut self.inner).poll_write_vectored(cx, bufs);
        if let Poll::Ready(Ok(n)) = &r {
            self.counters.down.fetch_add(*n as u64, Ordering::Relaxed);
        }
        r
    }
    fn is_write_vectored(&self) -> bool {
        self.inner.is_write_vectored()
    }
}

/// A per-listener label, made once. Interned so a reload that rebuilds the
/// same listeners does not leak a fresh copy each time.
pub fn intern(label: String) -> &'static str {
    static LABELS: std::sync::Mutex<Vec<&'static str>> = std::sync::Mutex::new(Vec::new());
    let mut labels = LABELS.lock().unwrap();
    if let Some(existing) = labels.iter().find(|l| **l == label) {
        return existing;
    }
    let leaked: &'static str = Box::leak(label.into_boxed_str());
    labels.push(leaked);
    leaked
}

mod imp {
    use super::*;
    use dashmap::DashMap;
    use parking_lot::Mutex;
    use std::sync::LazyLock;
    use std::sync::atomic::AtomicUsize;
    use tokio::sync::Notify;

    pub use crate::client_proxy_selector::RuleSummary;

    static NEXT_ID: AtomicU64 = AtomicU64::new(1);
    static CAP: AtomicUsize = AtomicUsize::new(4096);
    static ACTIVE: AtomicU64 = AtomicU64::new(0);
    static TOTAL: AtomicU64 = AtomicU64::new(0);
    static UNTRACKED: AtomicU64 = AtomicU64::new(0);
    static FOLDED_UP: AtomicU64 = AtomicU64::new(0);
    static FOLDED_DOWN: AtomicU64 = AtomicU64::new(0);

    #[derive(Default)]
    struct InboundCounters {
        active: AtomicU64,
        total: AtomicU64,
        up: AtomicU64,
        down: AtomicU64,
    }

    pub struct Entry {
        id: u64,
        inbound: &'static str,
        network: Network,
        source: SocketAddr,
        started: std::time::SystemTime,
        counters: Arc<ConnectionCounters>,
        destination: Mutex<Option<NetLocation>>,
        sniffed_host: Mutex<Option<Arc<str>>>,
        chain: Mutex<Option<Arc<str>>>,
        group: Mutex<Option<Arc<str>>>,
        rule: Mutex<Option<usize>>,
        rules: Mutex<Option<Arc<[RuleSummary]>>>,
        close: Notify,
    }

    struct Registry {
        entries: DashMap<u64, Arc<Entry>>,
        inbounds: DashMap<&'static str, InboundCounters>,
        rule_lists: Mutex<Vec<Arc<[RuleSummary]>>>,
    }

    static REGISTRY: LazyLock<Registry> = LazyLock::new(|| Registry {
        entries: DashMap::new(),
        inbounds: DashMap::new(),
        rule_lists: Mutex::new(Vec::new()),
    });

    #[cfg(test)]
    pub static CAP_TEST_LOCK: std::sync::Mutex<()> = std::sync::Mutex::new(());

    /// `None` over the cap: served, not tracked.
    pub struct ConnectionHandle {
        entry: Option<Arc<Entry>>,
    }

    pub fn set_cap(cap: usize) {
        CAP.store(cap.max(1), Ordering::Relaxed);
    }

    pub fn register(source: SocketAddr, inbound: &'static str, network: Network) -> ConnectionHandle {
        if REGISTRY.entries.len() >= CAP.load(Ordering::Relaxed) {
            UNTRACKED.fetch_add(1, Ordering::Relaxed);
            return ConnectionHandle { entry: None };
        }
        let id = NEXT_ID.fetch_add(1, Ordering::Relaxed);
        let entry = Arc::new(Entry {
            id,
            inbound,
            network,
            source,
            started: std::time::SystemTime::now(),
            counters: Arc::new(ConnectionCounters::default()),
            destination: Mutex::new(None),
            sniffed_host: Mutex::new(None),
            chain: Mutex::new(None),
            group: Mutex::new(None),
            rule: Mutex::new(None),
            rules: Mutex::new(None),
            close: Notify::new(),
        });
        REGISTRY.entries.insert(id, entry.clone());
        ACTIVE.fetch_add(1, Ordering::Relaxed);
        TOTAL.fetch_add(1, Ordering::Relaxed);
        {
            let per = REGISTRY.inbounds.entry(inbound).or_default();
            per.active.fetch_add(1, Ordering::Relaxed);
            per.total.fetch_add(1, Ordering::Relaxed);
        }
        ConnectionHandle { entry: Some(entry) }
    }

    pub fn counted<S: AsyncStream>(stream: S, handle: &ConnectionHandle) -> CountingStream<S> {
        let counters = match &handle.entry {
            Some(e) => e.counters.clone(),
            // Over the cap: count into atomics nobody reads, so the call
            // sites do not branch.
            None => Arc::new(ConnectionCounters::default()),
        };
        CountingStream::new(stream, counters)
    }

    impl ConnectionHandle {
        pub fn set_destination(&self, destination: &NetLocation) {
            if let Some(e) = &self.entry {
                *e.destination.lock() = Some(destination.clone());
            }
        }
        pub fn set_sniffed_host(&self, host: &str) {
            if let Some(e) = &self.entry {
                *e.sniffed_host.lock() = Some(Arc::from(host));
            }
        }
        pub fn set_route(
            &self,
            chain: Option<Arc<str>>,
            group: Option<Arc<str>>,
            rule: Option<usize>,
            rules: Option<Arc<[RuleSummary]>>,
        ) {
            if let Some(e) = &self.entry {
                *e.chain.lock() = chain;
                *e.group.lock() = group;
                *e.rule.lock() = rule;
                *e.rules.lock() = rules;
            }
        }
        pub async fn closed(&self) {
            match &self.entry {
                Some(e) => e.close.notified().await,
                None => std::future::pending().await,
            }
        }
        pub fn counters(&self) -> Option<Arc<ConnectionCounters>> {
            self.entry.as_ref().map(|e| e.counters.clone())
        }
    }

    impl Drop for ConnectionHandle {
        fn drop(&mut self) {
            let Some(e) = self.entry.take() else { return };
            REGISTRY.entries.remove(&e.id);
            let up = e.counters.up.load(Ordering::Relaxed);
            let down = e.counters.down.load(Ordering::Relaxed);
            ACTIVE.fetch_sub(1, Ordering::Relaxed);
            FOLDED_UP.fetch_add(up, Ordering::Relaxed);
            FOLDED_DOWN.fetch_add(down, Ordering::Relaxed);
            if let Some(per) = REGISTRY.inbounds.get(e.inbound) {
                per.active.fetch_sub(1, Ordering::Relaxed);
                per.up.fetch_add(up, Ordering::Relaxed);
                per.down.fetch_add(down, Ordering::Relaxed);
            }
        }
    }

    #[derive(Debug, Clone)]
    pub struct ConnectionSnapshot {
        pub id: u64,
        pub inbound: &'static str,
        pub network: Network,
        pub source: SocketAddr,
        pub destination: Option<String>,
        pub destination_host: Option<String>,
        pub destination_port: u16,
        pub sniffed_host: Option<String>,
        pub chain: Option<String>,
        pub group: Option<String>,
        pub rule: Option<usize>,
        pub rule_summary: Option<RuleSummary>,
        pub started: std::time::SystemTime,
        pub up: u64,
        pub down: u64,
    }

    fn snapshot_entry(e: &Entry) -> ConnectionSnapshot {
        let destination = e.destination.lock().clone();
        let rule = *e.rule.lock();
        let rule_summary = rule.and_then(|i| e.rules.lock().as_ref().and_then(|r| r.get(i).cloned()));
        ConnectionSnapshot {
            id: e.id,
            inbound: e.inbound,
            network: e.network,
            source: e.source,
            destination: destination.as_ref().map(|d| d.to_string()),
            destination_host: destination.as_ref().map(|d| d.address().to_string()),
            destination_port: destination.as_ref().map(|d| d.port()).unwrap_or(0),
            sniffed_host: e.sniffed_host.lock().as_deref().map(str::to_string),
            chain: e.chain.lock().as_deref().map(str::to_string),
            group: e.group.lock().as_deref().map(str::to_string),
            rule,
            rule_summary,
            started: e.started,
            up: e.counters.up.load(Ordering::Relaxed),
            down: e.counters.down.load(Ordering::Relaxed),
        }
    }

    pub fn snapshot() -> Vec<ConnectionSnapshot> {
        let mut out: Vec<_> = REGISTRY.entries.iter().map(|kv| snapshot_entry(kv.value())).collect();
        out.sort_by_key(|c| c.id);
        out
    }

    pub fn close(id: u64) -> bool {
        match REGISTRY.entries.get(&id) {
            Some(e) => {
                e.close.notify_one();
                true
            }
            None => false,
        }
    }

    pub fn close_all() -> usize {
        let mut n = 0;
        for kv in REGISTRY.entries.iter() {
            kv.value().close.notify_one();
            n += 1;
        }
        n
    }

    #[derive(Debug, Clone, Copy, PartialEq, Eq)]
    pub struct Totals {
        pub active: usize,
        pub total: u64,
        pub untracked: u64,
        pub up: u64,
        pub down: u64,
    }

    /// Folded totals plus the live entries. O(live), bounded by the cap.
    pub fn totals() -> Totals {
        let mut up = FOLDED_UP.load(Ordering::Relaxed);
        let mut down = FOLDED_DOWN.load(Ordering::Relaxed);
        for kv in REGISTRY.entries.iter() {
            up += kv.value().counters.up.load(Ordering::Relaxed);
            down += kv.value().counters.down.load(Ordering::Relaxed);
        }
        Totals {
            active: REGISTRY.entries.len(),
            total: TOTAL.load(Ordering::Relaxed),
            untracked: UNTRACKED.load(Ordering::Relaxed),
            up,
            down,
        }
    }

    #[derive(Debug, Clone, PartialEq, Eq)]
    pub struct InboundStats {
        pub inbound: &'static str,
        pub active: u64,
        pub total: u64,
        pub up: u64,
        pub down: u64,
    }

    pub fn inbound_stats() -> Vec<InboundStats> {
        let mut out: Vec<_> = REGISTRY
            .inbounds
            .iter()
            .map(|kv| InboundStats {
                inbound: kv.key(),
                active: kv.value().active.load(Ordering::Relaxed),
                total: kv.value().total.load(Ordering::Relaxed),
                up: kv.value().up.load(Ordering::Relaxed),
                down: kv.value().down.load(Ordering::Relaxed),
            })
            .collect();
        out.sort_by_key(|i| i.inbound);
        out
    }

    pub fn install_rule_list(list: Arc<[RuleSummary]>) {
        let mut lists = REGISTRY.rule_lists.lock();
        if !lists.iter().any(|l| **l == *list) {
            lists.push(list);
        }
    }

    pub fn reset_rule_lists() {
        REGISTRY.rule_lists.lock().clear();
    }

    pub fn rule_lists() -> Vec<Arc<[RuleSummary]>> {
        REGISTRY.rule_lists.lock().clone()
    }
}

pub async fn request(addr: SocketAddr, method: &str, path: &str, headers: &[(&str, &str)], body: &str) -> Reply {
    let mut stream = tokio::net::TcpStream::connect(addr).await.unwrap();
    let mut req = format!("{method} {path} HTTP/1.1\r\nHost: x\r\nConnection: close\r\nContent-Length: {}\r\n", body.len());
    for (k, v) in headers {
        req.push_str(&format!("{k}: {v}\r\n"));
    }
    req.push_str("\r\n");
    req.push_str(body);
    stream.write_all(req.as_bytes()).await.unwrap();
    let mut raw = Vec::new();
    stream.read_to_end(&mut raw).await.unwrap();
    let text = String::from_utf8_lossy(&raw).to_string();
    let (head, body) = text.split_once("\r\n\r\n").unwrap_or((&text, ""));
    let mut lines = head.split("\r\n");
    let code = lines.next().unwrap().split_whitespace().nth(1).unwrap().parse().unwrap();
    let headers = lines.filter_map(|l| l.split_once(": ")).map(|(k, v)| (k.to_string(), v.to_string())).collect();
    Reply { code, headers, body: body.to_string() }
}

}

    pub socks: u16,
    pub http: u16,
    pub mixed: u16,

    pub fn from_configs(configs: &[crate::config::Config]) -> Self {
        use crate::config::{BindLocation, Config, ServerProxyConfig as P};
        let mut ports = Ports::default();
        for config in configs {
            match config {
                Config::TunServer(_) => ports.tun = true,
                Config::Server(s) => {
                    let BindLocation::Address(addresses) = &s.bind_location else { continue };
                    let Some(first) = addresses.iter().next() else { continue };

                        P::Http { .. } => &mut ports.http,
                        P::Mixed { .. } => &mut ports.mixed,
                        _ => continue,
                    };
                    if *slot == 0 {
                        *slot = port;
                    }
                }
                _ => {}
            }
        }
        ports
    }

pub struct ApiState {
    pub config: ClashApiConfig,
    pub ports: Ports,
    pub started: std::time::Instant,
    pub log: Option<Arc<crate::control::logs::BroadcastLogWriter>>,

pub async fn serve_on(
    listener: tokio::net::TcpListener,
    state: Arc<ApiState>,
    mut shutdown: tokio::sync::oneshot::Receiver<()>,
) -> std::io::Result<()> {
    log::info!("clash api listening on {}", state.config.listen);
    loop {
        let accepted = tokio::select! {
            r = listener.accept() => r,
            _ = &mut shutdown => return Ok(()),
        };
        let (stream, _) = match accepted {
            Ok(v) => v,
            Err(e) => {
                log::error!("clash api accept failed: {e}");
                continue;
            }
        };
        let state = state.clone();
        tokio::spawn(async move {
            let io = hyper_util::rt::TokioIo::new(stream);
            let svc = service_fn(move |req| {
                let state = state.clone();
                async move { Ok::<_, Infallible>(route(req, state).await) }
            });
            // `with_upgrades` so Task 7's WebSocket arms can take the socket.
            let _ = hyper::server::conn::http1::Builder::new()
                .serve_connection(io, svc)
                .with_upgrades()
                .await;
        });
    }
}

fn authorized(req: &Request<Incoming>, secret: &str) -> bool {
    let is_upgrade = req.headers().get("upgrade").is_some_and(|v| v.as_bytes().eq_ignore_ascii_case(b"websocket"));
    if is_upgrade
        && let Some(token) = query_param(req.uri().query(), "token")
    {
        return token.as_bytes().ct_eq(secret.as_bytes()).into();
    }
    let Some(value) = req.headers().get(hyper::header::AUTHORIZATION).and_then(|v| v.to_str().ok()) else {
        return false;
    };
    let Some(bearer) = value.strip_prefix("Bearer ") else { return false };
    bearer.as_bytes().ct_eq(secret.as_bytes()).into()
}

pub(crate) fn query_param(query: Option<&str>, name: &str) -> Option<String> {
    query?
        .split('&')
        .filter_map(|kv| kv.split_once('='))
        .find(|(k, _)| *k == name)
        .map(|(_, v)| v.to_string())
}

fn cors_origin(headers: &HeaderMap, allow: &[String]) -> Option<String> {
    if allow.is_empty() {
        return Some("*".to_string());
    }
    let origin = headers.get(hyper::header::ORIGIN)?.to_str().ok()?;
    allow.iter().any(|a| a == origin).then(|| origin.to_string())
}

fn with_cors(mut resp: Response<ApiBody>, origin: Option<String>) -> Response<ApiBody> {
    if let Some(origin) = origin {
        let h = resp.headers_mut();
        h.insert("access-control-allow-origin", origin.parse().unwrap());
        h.insert("access-control-allow-headers", "Authorization, Content-Type".parse().unwrap());
        h.insert("access-control-allow-methods", "GET, POST, PUT, PATCH, DELETE, OPTIONS".parse().unwrap());
    }
    resp
}

pub(crate) fn body(text: String) -> ApiBody {
    Full::new(Bytes::from(text)).map_err(|never| match never {}).boxed()
}

pub(crate) fn json(status: StatusCode, value: serde_json::Value) -> Response<ApiBody> {
    Response::builder()
        .status(status)
        .header("content-type", "application/json")
        .body(body(value.to_string()))
        .unwrap()
}

pub(crate) fn error(status: StatusCode, message: &str) -> Response<ApiBody> {
    json(status, serde_json::json!({ "message": message }))
}

pub(crate) async fn read_body(req: Request<Incoming>) -> Result<Bytes, Response<ApiBody>> {
    const LIMIT: usize = 64 * 1024;
    let limited = http_body_util::Limited::new(req.into_body(), LIMIT);
    match limited.collect().await {
        Ok(collected) => Ok(collected.to_bytes()),
        Err(_) => Err(error(StatusCode::BAD_REQUEST, "body too large or unreadable")),
    }
}

pub(crate) async fn route(req: Request<Incoming>, state: Arc<ApiState>) -> Response<ApiBody> {
    let origin = cors_origin(req.headers(), &state.config.allow_origins);
    if req.method() == Method::OPTIONS {
        let resp = Response::builder().status(StatusCode::NO_CONTENT).body(body(String::new())).unwrap();
        return with_cors(resp, origin);
    }
    if let Some(secret) = &state.config.secret
        && !authorized(&req, secret)
    {
        return with_cors(error(StatusCode::UNAUTHORIZED, "Unauthorized"), origin);
    }
    let path = req.uri().path().trim_end_matches('/').to_string();
    let segments: Vec<&str> = path.split('/').filter(|s| !s.is_empty()).collect();
    let resp = dispatch(req, &segments, &state).await;
    with_cors(resp, origin)
}

async fn dispatch(req: Request<Incoming>, segments: &[&str], state: &Arc<ApiState>) -> Response<ApiBody> {
    use render as r;
    match (req.method().clone(), segments) {
        (Method::GET, []) => json(StatusCode::OK, r::hello()),
        (Method::GET, ["version"]) => json(StatusCode::OK, r::version()),
        (Method::GET, ["configs"]) => json(StatusCode::OK, r::configs(state)),
        (Method::PATCH, ["configs"]) => {
            // Slice 2 gives `mode` meaning; until then every field is accepted
            // and ignored so a dashboard writing log-level sees no error.
            let _ = read_body(req).await;
            Response::builder().status(StatusCode::NO_CONTENT).body(body(String::new())).unwrap()
        }
        (Method::PUT, ["configs"]) => error(StatusCode::METHOD_NOT_ALLOWED, "Method Not Allowed"),
        (Method::GET, ["proxies"]) => json(StatusCode::OK, r::proxies(false)),
        (Method::GET, ["group"]) => json(StatusCode::OK, r::proxies(true)),
        (Method::GET, ["proxies", name]) | (Method::GET, ["group", name]) => match r::proxy(name) {
            Some(p) => json(StatusCode::OK, p),
            None => error(StatusCode::NOT_FOUND, "proxy not found"),
        },
        (Method::PUT, ["proxies", _]) | (Method::DELETE, ["proxies", _]) => error(StatusCode::METHOD_NOT_ALLOWED, "Method Not Allowed"),
        (Method::GET, ["rules"]) => json(StatusCode::OK, r::rules()),
        (Method::GET, ["connections"]) => json(StatusCode::OK, r::connections()),
        (Method::DELETE, ["connections"]) => {
            crate::connection_registry::close_all();
            Response::builder().status(StatusCode::NO_CONTENT).body(body(String::new())).unwrap()
        }
        (Method::DELETE, ["connections", id]) => match id.parse::<u64>() {
            Ok(id) if crate::connection_registry::close(id) => {
                Response::builder().status(StatusCode::NO_CONTENT).body(body(String::new())).unwrap()
            }
            _ => error(StatusCode::NOT_FOUND, "connection not found"),
        },
        (Method::GET, ["metrics"]) => Response::builder()
            .status(StatusCode::OK)
            .header("content-type", "text/plain; version=0.0.4; charset=utf-8")
            .body(body(metrics::render()))
            .unwrap(),
        (_, ["connections", ..]) | (_, ["proxies", ..]) | (_, ["group", ..]) | (_, ["rules"]) | (_, ["version"]) | (_, ["metrics"]) | (_, []) => {
            error(StatusCode::METHOD_NOT_ALLOWED, "Method Not Allowed")
        }
        _ => error(StatusCode::NOT_FOUND, "Not Found"),
    }
}

fn rfc3339(t: std::time::SystemTime) -> String {
    // mihomo sends RFC 3339 with nanoseconds; dashboards parse it with Date.
    let secs = t.duration_since(std::time::UNIX_EPOCH).map(|d| d.as_secs()).unwrap_or(0);
    let days = secs / 86_400;
    let (h, m, s) = ((secs % 86_400) / 3600, (secs % 3600) / 60, secs % 60);
    // Civil-from-days, Howard Hinnant's algorithm.
    let z = days as i64 + 719_468;
    let era = z.div_euclid(146_097);
    let doe = z.rem_euclid(146_097);
    let yoe = (doe - doe / 1460 + doe / 36_524 - doe / 146_096) / 365;
    let y = yoe + era * 400;
    let doy = doe - (365 * yoe + yoe / 4 - yoe / 100);
    let mp = (5 * doy + 2) / 153;
    let d = doy - (153 * mp + 2) / 5 + 1;
    let mo = if mp < 10 { mp + 3 } else { mp - 9 };
    let y = if mo <= 2 { y + 1 } else { y };
    format!("{y:04}-{mo:02}-{d:02}T{h:02}:{m:02}:{s:02}Z")
}

//! Resident set size from the OS. See the spec, "Traffic and memory".

#[cfg(target_os = "linux")]
pub fn rss() -> u64 {
    let Ok(statm) = std::fs::read_to_string("/proc/self/statm") else { return 0 };
    let pages: u64 = statm.split_whitespace().nth(1).and_then(|p| p.parse().ok()).unwrap_or(0);
    let page = unsafe { libc::sysconf(libc::_SC_PAGESIZE) };
    pages * page.max(0) as u64
}

#[cfg(target_os = "macos")]
pub fn rss() -> u64 {
    let mut info: libc::mach_task_basic_info = unsafe { std::mem::zeroed() };
    let mut count = libc::MACH_TASK_BASIC_INFO_COUNT;
    let kr = unsafe {
        libc::task_info(
            libc::mach_task_self(),
            libc::MACH_TASK_BASIC_INFO,
            &mut info as *mut libc::mach_task_basic_info as libc::task_info_t,
            &mut count,
        )
    };
    if kr == libc::KERN_SUCCESS { info.resident_size } else { 0 }
}

//! A server-side WebSocket for one-way text frames, over the handshake and
//! frame packer the transport module already has.

use std::future::Future;

use hyper::body::Incoming;
use hyper::{Request, Response, StatusCode};
use hyper_util::rt::TokioIo;
use tokio::io::{AsyncReadExt, AsyncWriteExt};

use super::{ApiBody, body, error};

pub fn is_upgrade(req: &Request<Incoming>) -> bool {
    req.headers().get("upgrade").is_some_and(|v| v.as_bytes().eq_ignore_ascii_case(b"websocket"))
}

pub trait Sink: Send {
    fn send(&mut self, text: &str) -> impl Future<Output = std::io::Result<()>> + Send;
    fn closed(&mut self) -> impl Future<Output = ()> + Send;
}

pub struct TextSink {
    io: TokioIo<hyper::upgrade::Upgraded>,
    scratch: Vec<u8>,
}

impl Sink for TextSink {
    async fn send(&mut self, text: &str) -> std::io::Result<()> {
        self.scratch.clear();
        self.scratch.resize(text.len() + 14, 0);
        let n = crate::websocket::websocket_stream::pack_frame(0x1, false, text.as_bytes(), &mut self.scratch);
        self.io.write_all(&self.scratch[..n]).await
    }

    /// Reads client frames: a close (opcode 8) or EOF ends the stream; a
    /// ping (9) is answered with a pong (10); anything else is skipped.
    async fn closed(&mut self) {
        let mut hdr = [0u8; 2];
        loop {
            if self.io.read_exact(&mut hdr).await.is_err() {
                return;
            }
            let opcode = hdr[0] & 0x0f;
            let masked = hdr[1] & 0x80 != 0;
            let mut len = (hdr[1] & 0x7f) as usize;
            if len == 126 {
                let mut l = [0u8; 2];
                if self.io.read_exact(&mut l).await.is_err() { return; }
                len = u16::from_be_bytes(l) as usize;
            } else if len == 127 {
                let mut l = [0u8; 8];
                if self.io.read_exact(&mut l).await.is_err() { return; }
                len = u64::from_be_bytes(l) as usize;
            }
            let mut mask = [0u8; 4];
            if masked && self.io.read_exact(&mut mask).await.is_err() { return; }
            let mut payload = vec![0u8; len.min(64 * 1024)];
            if self.io.read_exact(&mut payload).await.is_err() { return; }
            if masked {
                for (i, b) in payload.iter_mut().enumerate() { *b ^= mask[i % 4]; }
            }
            match opcode {
                0x8 => {
                    let mut out = vec![0u8; payload.len() + 14];
                    let n = crate::websocket::websocket_stream::pack_frame(0x8, false, &payload, &mut out);
                    let _ = self.io.write_all(&out[..n]).await;
                    return;
                }
                0x9 => {
                    let mut out = vec![0u8; payload.len() + 14];
                    let n = crate::websocket::websocket_stream::pack_frame(0xA, false, &payload, &mut out);
                    if self.io.write_all(&out[..n]).await.is_err() { return; }
                }
                _ => {}
            }
        }
    }
}

/// Answer the handshake and run `on_socket` on the upgraded stream.
pub fn upgrade<F, Fut>(mut req: Request<Incoming>, on_socket: F) -> Response<ApiBody>
where
    F: FnOnce(TextSink) -> Fut + Send + 'static,
    Fut: Future<Output = ()> + Send + 'static,
{
    let Some(key) = req.headers().get("sec-websocket-key").and_then(|v| v.to_str().ok()).map(str::to_string) else {
        return error(StatusCode::BAD_REQUEST, "missing Sec-WebSocket-Key");
    };
    let accept = crate::websocket::websocket_handler::create_websocket_key_response(key);
    let on_upgrade = hyper::upgrade::on(&mut req);
    tokio::spawn(async move {
        match on_upgrade.await {
            Ok(upgraded) => on_socket(TextSink { io: TokioIo::new(upgraded), scratch: Vec::new() }).await,
            Err(e) => log::debug!("clash api upgrade failed: {e}"),
        }
    });
    Response::builder()
        .status(StatusCode::SWITCHING_PROTOCOLS)
        .header("upgrade", "websocket")
        .header("connection", "Upgrade")
        .header("sec-websocket-accept", accept)
        .body(body(String::new()))
        .unwrap()
}

async fn periodic<S: Sink, F: FnMut() -> String + Send>(mut sink: S, every: Duration, mut tick: F) {

pub async fn logs<S: Sink>(state: Arc<ApiState>, filter: log::LevelFilter, mut sink: S) {
    let Some(ring) = state.log.clone() else { return };
    let (backlog, mut rx) = ring.subscribe();
    let frame = |line: &crate::control::logs::LogLine| {
        let (category, tag) = category_for(&line.target);
        serde_json::json!({ "type": level_name(line.level), "payload": format!("{category}[{tag}]: {}", line.message) }).to_string()
    };
    for line in backlog.iter().filter(|l| l.level <= filter) {
        if sink.send(&frame(line)).await.is_err() { return; }
    }
    loop {
        tokio::select! {
            next = rx.recv() => match next {
                Ok(line) if line.level <= filter => { if sink.send(&frame(&line)).await.is_err() { return; } }
                Ok(_) => {}
                // Lagged: the subscriber fell behind the ring; disconnect rather than buffer.
                Err(_) => return,
            },
            _ = sink.closed() => return,
        }
    }
}

/// The chunked fallback: JSON lines on a plain GET.
pub struct ChunkedSink {
    tx: tokio::sync::mpsc::Sender<Result<hyper::body::Frame<hyper::body::Bytes>, std::convert::Infallible>>,
}

impl Sink for ChunkedSink {
    async fn send(&mut self, text: &str) -> std::io::Result<()> {
        let mut line = text.to_string();
        line.push('\n');
        self.tx
            .send(Ok(hyper::body::Frame::data(hyper::body::Bytes::from(line))))
            .await
            .map_err(|_| std::io::Error::new(std::io::ErrorKind::BrokenPipe, "client went away"))
    }
    async fn closed(&mut self) {
        self.tx.closed().await
    }
}

/// The controller, started once and reconciled against each reload.
#[cfg(feature = "clash-api")]
struct ApiRunner {
    config: config::ClashApiConfig,
    stop: tokio::sync::oneshot::Sender<()>,
}

/// Same listen and secret: keep it. Anything else: replace it. None: stop it.
#[cfg(feature = "clash-api")]
async fn reconcile_api(
    current: Option<ApiRunner>,
    wanted: Option<&config::ClashApiConfig>,
    configs: &[config::Config],
) -> Option<ApiRunner> {
    if let (Some(cur), Some(want)) = (&current, wanted)
        && cur.config.listen == want.listen
        && cur.config.secret == want.secret
    {
        connection_registry::set_cap(want.max_tracked_connections);
        return current;
    }
    if let Some(cur) = current {
        println!("Stopping the Clash API on {}", cur.config.listen);
        let _ = cur.stop.send(());
    }
    let want = wanted?.clone();
    let listener = match tokio::net::TcpListener::bind(want.listen).await {
        Ok(l) => l,
        Err(e) => {
            eprintln!("Could not bind the Clash API on {}: {e}", want.listen);
            return None;
        }
    };
    connection_registry::set_cap(want.max_tracked_connections);
    let ring = clash_api::logs::install_ring(512);
    let state = std::sync::Arc::new(clash_api::ApiState {
        config: want.clone(),
        ports: clash_api::Ports::from_configs(configs),
        started: std::time::Instant::now(),
        log: Some(ring),
    });
    let (stop, rx) = tokio::sync::oneshot::channel();
    tokio::spawn(async move {
        if let Err(e) = clash_api::serve_on(listener, state, rx).await {
            eprintln!("Clash API stopped: {e}");
        }
    });
    Some(ApiRunner { config: want, stop })
}
```

`PreparedServers` keeps `server_configs` after launch for `Ports::from_configs`: in the serve loop, before `launch_servers(prepared)` consumes it, take `let api_wanted = prepared.clash_api.clone(); let ports_source = prepared.server_configs.clone();` (these are the validated `Config` values, cloneable), then after a successful launch:

```rust
            #[cfg(feature = "clash-api")]
            {
                api = reconcile_api(api.take(), api_wanted.as_ref(), &ports_source).await;
            }
```

with `#[cfg(feature = "clash-api")] let mut api: Option<ApiRunner> = None;` declared before the `loop`. On `shut_down`, nothing extra: the process exits.

Without the feature, `clash_api` on `PreparedServers` is unused: `let _ = prepared.clash_api;` under `#[cfg(not(feature = "clash-api"))]`, and if the block was present print one line: `eprintln!("clash_api is configured but this build has no clash-api feature; ignoring it");` (spec, "Configuration").
